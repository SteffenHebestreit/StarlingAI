⚡ What you'll need

The one-click launcher needs just one thing installed. Everything else runs inside Docker for you.

  • Docker Desktop (the only prerequisite) — docker.com  with Compose v2 included. Then double-click start.bat (Windows), start.command (macOS), or run ./start.sh (Linux).
  • ~16 GB RAM recommended — 8 GB minimum; more RAM = larger models possible
  • A model — your choice, picked in the wizard. Use an OpenAI-compatible endpoint you run (LM Studio, vLLM, llama.cpp…), an Anthropic API key, or a local model via Ollama that the wizard downloads for you (no key, nothing to install yourself).

Only if you want to develop from source: Node.js 22+, pnpm, and Git — see the manual / developer setup.

🗺 How it works

StarlingAI is a general-purpose, self-hosted AI agent swarm inspired by starling murmurations. Just as each starling follows simple local rules (avoid collision, match speed, stay close) to create complex emergent behavior, each agent in the swarm follows its own narrow rules and tool set to contribute to solutions that no single agent could produce alone.

A lightweight orchestrator receives your messages (from Telegram, Slack, Discord, WhatsApp, Email, or the web dashboard) and dynamically routes them to the right specialist agent — a researcher, coder, data analyst, browser automator, and more. The swarm can tackle any task domain by composing the right specialists at runtime.

For recurring request shapes, the orchestrator can also search the local workflow catalog first. Matching scenes and multi-step jobs are executed inline through search_workflows and run_workflow, so recurring paper, research, or browser-inspection packets stay reusable and auditable.

Everything runs in Docker containers on your own machine. Your data never leaves your network. You choose the language model in the setup wizard: an OpenAI-compatible endpoint you run (LM Studio, vLLM, llama.cpp…), an Anthropic key, or a local model via Ollama — no cloud key required unless you want one.
