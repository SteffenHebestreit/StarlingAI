🎬 Scenes & Automation

Define workflows once — let the swarm execute them using the right specialists automatically.

What is a scene?

A scene is a named, reusable task template that the swarm executes autonomously. Each scene defines a task and optionally constrains which agents can participate, what approval gates apply, and what webhooks to trigger. The swarm dynamically discovers the best specialists to handle each part of the task — you define the goal, not the step-by-step execution.

💡
Think of scenes as missions for the swarm. You define the objective and constraints, then the swarm composes the right specialists to accomplish it — like a flock of starlings responding to a signal.
How to create a scene

Via the dashboard

  1. Open http://localhost:3001
  2. Go to Settings → Scenes → New Scene
  3. Give the scene a name (e.g. daily_report) — no spaces, use underscores
  4. Add steps using the visual step builder
  5. Optionally add input variables and a schedule
  6. Click Save

Via starlingai.json

Declare scenes in your config file for version-controlled automation:

json
{
  "scenes": {
    "daily_report": {
      "description": "Compile and send a daily summary report",
      "schedule": "0 8 * * 1-5",
      "steps": [
        {
          "id": "gather_data",
          "agent": "researcher",
          "input": "Summarise the top 5 AI news items from today"
        },
        {
          "id": "write_report",
          "agent": "summarizer",
          "input": "{{steps.gather_data.output}} — format as a short bullet-point email"
        },
        {
          "id": "send_email",
          "agent": "notification_router",
          "input": "Send to {{vars.recipientEmail}}: {{steps.write_report.output}}"
        }
      ]
    }
  }
}
Triggering a scene

Scenes can be triggered in three ways:

1. From chat

Send a message to the bot with the /run command:

chat
/run daily_report

# With variables:
/run daily_report recipientEmail=steffen@example.com

2. Via the REST API

bash
curl -X POST \
  "http://localhost:8765/api/scenes/daily_report/run?key=$SCENE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"vars": {"recipientEmail": "steffen@example.com"}}'
ℹ️
Get your SCENE_KEY from the dashboard under Settings → Scenes → API Keys. Keep it secret — it can trigger any scene in your instance.

3. From the dashboard

Navigate to Settings → Scenes, find your scene, and click the Run button. You can provide variable values via the run dialog.

Example: daily report scene

Here's a full scene definition that gathers AI news, writes a report, and emails it — every weekday at 8 AM.

json5
{
  scenes: {
    daily_report: {
      description: "Daily AI news digest",
      // Cron: weekdays at 8:00 AM
      schedule: "0 8 * * 1-5",
      // Variables with defaults
      vars: {
        recipientEmail: { type: "string", required: true },
        topN: { type: "number", default: 5 }
      },
      steps: [
        {
          id: "research",
          agent: "researcher",
          input: "Find the top {{vars.topN}} AI news items published today. Include source URLs."
        },
        {
          id: "summarise",
          agent: "summarizer",
          input: "Condense the following into a concise email body (bullet points):\n{{steps.research.output}}"
        },
        {
          id: "send",
          agent: "notification_router",
          input: "Send an email to {{vars.recipientEmail}} with subject 'Daily AI Digest' and body:\n{{steps.summarise.output}}"
        }
      ]
    }
  }
}
Human-in-the-loop approval

Add approval gates to pause a scene before executing sensitive steps. The orchestrator will send an approval request to your chosen channel and wait for you to confirm before continuing.

json5
{
  scenes: {
    outreach_campaign: {
      description: "Draft and send outreach emails",
      // Pause before executing these step IDs
      humanInLoopSteps: ["send_emails"],
      // Send approval request to this channel
      approvalChannel: "slack",
      steps: [
        {
          id: "draft",
          agent: "email_drafter",
          input: "Draft 3 cold outreach emails for: {{vars.targetCompanies}}"
        },
        {
          id: "send_emails",
          agent: "notification_router",
          input: "Send the following emails: {{steps.draft.output}}"
        }
      ]
    }
  }
}

When the scene reaches a humanInLoopSteps step:

  1. The bot sends you a message on the approvalChannel showing what it's about to do
  2. It waits (up to 24 hours by default)
  3. Reply "approve" to continue, or "reject" to abort the scene
⚠️
The approvalChannel must be connected and the requesting user must have a valid pairing for that channel. See the Channels guide for setup instructions.
Scene variables & templating

Scenes use a simple double-brace templating syntax. Variables are resolved at runtime from three sources, in order of priority:

  1. Run-time input — provided when triggering via chat or API
  2. Scene defaults — declared in the vars section
  3. Previous step outputs — referenced as {"{{steps.STEP_ID.output}}"}
text
Available template variables:

{{vars.NAME}}              — input variable (e.g. {{vars.recipientEmail}})
{{steps.STEP_ID.output}}   — text output of a previous step
{{steps.STEP_ID.success}}  — boolean: did the step succeed?
{{env.SAI_MASTER_KEY}}      — environment variable (restricted list)
{{now}}                    — current ISO timestamp
{{today}}                  — current date (YYYY-MM-DD)
Scheduling scenes

The schedule field accepts standard 5-field cron expressions. The timezone defaults to UTC; set scheduleTimezone to change it.

json5
{
  scenes: {
    weekly_summary: {
      schedule: "0 9 * * 1",          // Every Monday at 9:00 AM
      scheduleTimezone: "Europe/Berlin",
      // ...
    }
  }
}

Common cron patterns

ExpressionMeaning
0 8 * * 1-5Weekdays at 8:00 AM
0 9 * * 1Every Monday at 9:00 AM
*/30 * * * *Every 30 minutes
0 0 1 * *First day of each month at midnight
0 12 * * *Every day at noon
