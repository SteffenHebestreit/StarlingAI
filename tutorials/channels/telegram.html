✈️ TelegramEasy~5 min

Connect Telegram

The fastest way to start chatting with your agents. All you need is a Telegram account.

1
Create a bot via BotFather Done

BotFather is the official Telegram bot that creates and manages other bots. Open Telegram and search for @BotFather.

  1. Send /newbot to @BotFather
  2. Choose a display name (e.g. "My StarlingAI")
  3. Choose a username — must end in bot (e.g. mystarlingai_bot)
  4. BotFather replies with your bot token

Your token will look like:

text
123456789:AAF-FakeToken-example_here
🔒
Treat your bot token like a password. Anyone with this token can control your bot. Never share it publicly or commit it to version control.
2
Add token to .env Done

Open your .env file and add the token:

.env
TELEGRAM_BOT_TOKEN=123456789:AAF-YourActualTokenHere

Then restart the gateway to pick up the change:

bash
docker compose restart gateway
3
Enable in the dashboard Done
  1. Open http://localhost:3001
  2. Go to Settings → Channels → Telegram
  3. Toggle the channel On
  4. Set your preferred dmPolicy (default: pairing)
  5. Click Save
🖥
Screenshot: Settings → Channels → Telegram toggle
4
Optional: restrict to your user ID Done

If you want only yourself (or a specific list of people) to message the bot, use allowlist policy and add your Telegram user ID.

Find your Telegram user ID

Message @userinfobot on Telegram — it replies with your numeric user ID.

Add to config

json
{
  "channels": {
    "telegram": {
      "enabled": true,
      "dmPolicy": "allowlist",
      "allowedUsers": ["123456789"]
    }
  }
}
5
Test it Done
  1. Open Telegram and search for your bot username (e.g. @mystarlingai_bot)
  2. Send /start
  3. The bot should reply with a welcome message
  4. If using pairing mode: it will tell you to run /pair CODE
🔑
Pairing mode: on first message the bot asks you to authorize. Find your pairing code in the gateway logs:
bash
docker compose logs gateway | grep "Pairing code"
Then send /pair YOUR_CODE in the Telegram chat. You're now authorized permanently.
✅
Once paired, send any message to test agent routing. Try: "What is the capital of France?" — the summarizer or researcher agent should respond within a few seconds.
