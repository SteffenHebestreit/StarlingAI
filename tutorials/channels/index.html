📡 Channels

The swarm is reachable from 6 channels. Each channel is an entry point into the same agent swarm — the same specialists, routing, and guardrails serve every channel.

DM policy — controlling who can message your bot

Every channel has a dmPolicy setting that controls which users can send messages to your agents. Set it via the dashboard or in starlingai.json.

Policy Behaviour Recommended?
pairing Users must send /pair CODE to authorize. The pairing code is printed to gateway logs at startup. Once paired, the user is remembered permanently. Default — recommended
allowlist Only user IDs listed in allowedUsers can send messages. All other messages are silently ignored. Good for teams
open Anyone who knows the bot can message it. No authorization required. Not recommended for bots with a public username. Use with caution
disabled The channel adapter is loaded but all incoming messages are rejected. Useful for temporarily disabling a channel without removing the config. For maintenance

Example config

json
{
  "channels": {
    "telegram": {
      "enabled": true,
      "dmPolicy": "pairing"
    },
    "slack": {
      "enabled": true,
      "dmPolicy": "allowlist",
      "allowedUsers": ["U012AB3CD", "U987ZY6WX"]
    }
  }
}
ℹ️
For pairing mode: the pairing code is printed to gateway logs on startup. Run docker compose logs gateway | grep "Pairing code" to find it.
