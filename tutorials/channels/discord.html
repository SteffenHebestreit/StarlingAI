🎮 DiscordEasy~10 min

Connect Discord

Add a bot to your Discord server and chat with your agents from any channel.

1
Create a Discord Application Done
  1. Go to discord.com/developers/applications
  2. Click New Application (top-right)
  3. Enter a name (e.g. StarlingAI)
  4. Accept the Terms of Service and click Create

You'll land on the General Information page of your new application.

2
Create a Bot & copy the token Done
  1. In the left sidebar, click Bot
  2. Click Add Bot → Yes, do it!
  3. Under the bot's username, click Reset Token
  4. Confirm and copy the token — you won't be able to see it again!
⚠️
Save the token somewhere safe immediately. If you lose it, you'll need to reset it (which invalidates the old one).
3
Enable Privileged Intents Done

StarlingAI needs the Message Content Intent to read message text.

Still on the Bot page, scroll down to Privileged Gateway Intents:

IntentRequired?
Message Content Intent Required
Server Members Intent Optional
Presence Intent Not needed

Toggle Message Content Intent on and click Save Changes.

⚠️
Without the Message Content Intent, the bot will receive events but cannot read message text — it will appear to silently ignore all messages.
4
Invite the bot to your server Done
  1. In the left sidebar, click OAuth2 → URL Generator
  2. Under Scopes, check: bot
  3. Under Bot Permissions, check:
    • Send Messages
    • Read Message History
    • Read Messages / View Channels
  4. Copy the generated URL at the bottom of the page
  5. Open the URL in a new browser tab
  6. Select the server to add the bot to and click Authorize

The bot now appears in your server's member list (offline until the gateway starts).

5
Configure in dashboard Done
  1. Open http://localhost:3001
  2. Go to Settings → Channels → Discord
  3. Toggle On
  4. Paste your bot token
  5. Optionally enter Guild IDs to restrict which servers the bot responds in
  6. Set dmPolicy
  7. Click Save

Restrict to specific servers (optional)

json
{
  "channels": {
    "discord": {
      "enabled": true,
      "dmPolicy": "pairing",
      "allowedGuildIds": ["123456789012345678"]
    }
  }
}

Find your Guild ID by right-clicking a server icon in Discord → Copy Server ID (enable Developer Mode in Discord settings first).

6
Test it Done
  1. The bot should appear online in your Discord server
  2. Go to any channel the bot has access to
  3. Send a message mentioning the bot: @StarlingAI hello
  4. Or send a DM to the bot directly
  5. If using pairing mode, send /pair CODE first
✅
The bot responds in the same channel you messaged it from. For DMs, it responds in the DM thread. For channel messages, it replies in-thread to avoid spamming the channel.
