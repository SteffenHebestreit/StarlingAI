Connect WhatsApp

Use the Meta WhatsApp Business API to receive and send messages via WhatsApp.

⚠️
WhatsApp requires a public webhook URL. Your StarlingAI instance must be reachable from the internet. For local testing, use a tunnelling service like ngrok or Cloudflare Tunnel.
1
Create a Meta Developer Account & App Done
  1. Go to developers.facebook.com
  2. Log in with a Facebook account
  3. Click My Apps → Create App
  4. Select app type: Business
  5. Enter an app name and click Create App
ℹ️
You'll need to link a Business Portfolio or create a new one. For personal/hobbyist use a personal portfolio works fine.
2
Add WhatsApp product & get a test number Done
  1. On the App Dashboard, scroll down to Add a product
  2. Find WhatsApp and click Set Up
  3. You'll be taken to the WhatsApp Getting Started page
  4. Under From, a test phone number is automatically created — note the Phone Number ID
  5. Under To, add your personal WhatsApp number as a test recipient (you'll receive a verification code)

Take note of both:

  • Phone Number ID — numeric ID, not the actual phone number
  • WhatsApp Business Account ID — shown at the top of the page
3
Configure a webhook Done
  1. In the left sidebar, click WhatsApp → Configuration
  2. Under Webhook, click Edit
  3. Enter your Callback URL:
url
https://your-host/channels/whatsapp/webhook
  1. Enter a Verify Token — this is any string you choose (remember it for the dashboard)
  2. Click Verify and Save
  3. Under Webhook fields, click Manage
  4. Subscribe to: messages
ℹ️
Meta will send a GET request to your webhook URL to verify it. The StarlingAI gateway handles this automatically — just make sure it's running and publicly accessible before clicking Verify.
4
Generate a Permanent Access Token Done

The temporary access token on the Getting Started page expires. For production use, generate a permanent token:

  1. Go to business.facebook.com/settings
  2. Navigate to Users → System Users
  3. Create a new System User with Admin role
  4. Click Generate New Token
  5. Select your app, set expiration to Never
  6. Add permissions: whatsapp_business_messaging, whatsapp_business_management
  7. Click Generate Token and copy it
5
Configure in dashboard Done
  1. Open http://localhost:3001
  2. Go to Settings → Channels → WhatsApp
  3. Toggle On
  4. Fill in all four fields:
FieldWhere to find it
Access TokenGenerated in step 4
Phone Number IDWhatsApp → Getting Started → From number
Verify TokenThe string you chose in step 3
App SecretApp Dashboard → Settings → Basic → App Secret
  1. Click Save
6
Add App Secret for webhook security Done

StarlingAI verifies every inbound webhook payload using HMAC-SHA256 with your App Secret. This ensures messages actually come from Meta and haven't been tampered with.

🔒
If the appSecret field is empty, signature verification is skipped. This is not recommended for production — an attacker could send fake webhook events to your endpoint. Always configure appSecret for any publicly accessible deployment.

Find your App Secret:

  1. Go to the App Dashboard → App Settings → Basic
  2. Click Show next to App Secret
  3. Copy and paste it into the App Secret field in the dashboard

Test your setup

Send a WhatsApp message from the test recipient number you registered in step 2. The bot should reply within a few seconds.

✅
WhatsApp is now connected. Note that the test number has a sending limit (typically 1,000 conversations/day for the sandbox). For higher volume, you'll need a verified WhatsApp Business Account.
