Connect Slack

Add StarlingAI to your Slack workspace. Great for team collaboration.

ℹ️
You'll need to be a Workspace Admin (or have permission to install apps) to complete this setup. The app must be publicly accessible for the Events API — or use Socket Mode for local-only setups.
1
Create a Slack App Done
  1. Go to api.slack.com/apps
  2. Click Create New App
  3. Choose From scratch
  4. Enter an App Name (e.g. StarlingAI) and select your workspace
  5. Click Create App

You'll land on the App's configuration page. Keep this browser tab open — you'll need it throughout this guide.

2
Configure Bot Token Scopes Done
  1. In the left sidebar, click OAuth & Permissions
  2. Scroll down to Bot Token Scopes
  3. Add these scopes:
ScopePurpose
chat:writeSend messages as the bot
im:historyRead DM message history
im:readList DMs the bot is in
channels:historyRead messages in public channels
groups:historyRead messages in private channels
3
Enable Events (choose one mode) Done

StarlingAI supports two event delivery modes. Choose based on your setup:

Socket Mode — the bot connects out to Slack. No public URL needed. Best for local setups.

  1. Go to Socket Mode in the left sidebar
  2. Toggle Enable Socket Mode on
  3. Create an App-Level Token with the scope connections:write
  4. Copy the token — it starts with xapp-

Also enable event subscriptions:

  1. Go to Event Subscriptions in the sidebar
  2. Toggle Enable Events on
  3. Under Subscribe to bot events, add: message.im, message.channels, message.groups

Events API — Slack pushes events to your public URL. Requires StarlingAI to be reachable from the internet (e.g. via ngrok or a VPS).

  1. Go to Event Subscriptions in the left sidebar
  2. Toggle Enable Events on
  3. Set the Request URL to:
    url
    https://your-host/channels/slack/events
  4. Slack will verify the URL (StarlingAI handles the challenge automatically)
  5. Under Subscribe to bot events, add: message.im, message.channels, message.groups
4
Install to workspace Done
  1. In the left sidebar, click OAuth & Permissions
  2. Scroll to the top and click Install to Workspace
  3. Review the permissions and click Allow
  4. Copy the Bot User OAuth Token — it starts with xoxb-
text
xoxb-YOUR-WORKSPACE-ID-YOUR-BOT-TOKEN

Also grab the Signing Secret from Basic Information → App Credentials.

5
Configure in dashboard Done
  1. Open http://localhost:3001
  2. Go to Settings → Channels → Slack
  3. Toggle On
  4. Fill in the fields:
FieldValue
Bot TokenYour xoxb-... token
Signing SecretFrom Basic Information
App Tokenxapp-... token (Socket Mode only)
  1. Set dmPolicy to your preference
  2. Click Save
6
Test it Done
  1. In Slack, find the app in your workspace (search for its name)
  2. Click Messages to open a DM with the bot
  3. Send a message — the bot should reply
  4. If using pairing mode, send /pair CODE first
✅
The bot is now available to your entire workspace. Team members can find it via Apps in the Slack sidebar and DM it directly.
