Connect Email

Connect any IMAP/SMTP mailbox. StarlingAI polls for new emails and replies automatically.

ℹ️
The email channel uses IMAP polling (not push). StarlingAI checks for new emails every 30 seconds by default. Replies are sent via SMTP.
1
Get your IMAP/SMTP credentials Done

Most email providers support IMAP. The setup differs slightly by provider.

Gmail requires an App Password — your regular Google password won't work with IMAP when 2FA is enabled (which is required for app passwords).

  1. Go to myaccount.google.com/security
  2. Under How you sign in to Google, click 2-Step Verification
  3. Scroll to the bottom and click App passwords
  4. Select app: Mail, device: Other (name it "StarlingAI")
  5. Click Generate and copy the 16-character password

Use this app password as both your IMAP and SMTP password.

ℹ️
You also need to enable IMAP in Gmail: Settings → See all settings → Forwarding and POP/IMAP → Enable IMAP

For Outlook.com and Microsoft 365 accounts:

  • IMAP host: outlook.office365.com (port 993, SSL)
  • SMTP host: smtp.office365.com (port 587, STARTTLS)
  • Username: your full email address
  • Password: your Microsoft account password
⚠️
If your Microsoft 365 account has MFA, you may need to create an App Password via the Azure AD portal, or use OAuth2 authentication (contact your IT admin).

Any standard IMAP/SMTP server works. You'll need:

  • IMAP hostname and port (typically 993 with SSL)
  • SMTP hostname and port (typically 587 with STARTTLS, or 465 with SSL)
  • Your email username (usually full email address)
  • Your email password (or app password)

Check your email provider's documentation for the exact hostnames.

2
Configure in dashboard Done
  1. Open http://localhost:3001
  2. Go to Settings → Channels → Email
  3. Toggle On
  4. Fill in all fields:
FieldExample
IMAP Hostimap.gmail.com
IMAP Port993
IMAP Useryou@gmail.com
IMAP PasswordApp password (16 chars)
SMTP Hostsmtp.gmail.com
SMTP Port587
SMTP Useryou@gmail.com
SMTP PasswordSame app password
From AddressStarlingAI <you@gmail.com>
  1. Click Save
3
Poll interval Done

By default StarlingAI checks for new emails every 30 seconds. Adjust this in your config if you need faster or slower polling:

json
{
  "channels": {
    "email": {
      "enabled": true,
      "pollIntervalMs": 15000
    }
  }
}
⚠️
Very short poll intervals (under 10 seconds) may trigger rate limits on free email providers. 30 seconds is a safe default for most use cases.
4
Test it Done

Send an email to the configured address. StarlingAI should reply within ~30 seconds.

  • The subject of your email becomes the message sent to the orchestrator
  • The body is included as additional context
  • The reply comes from your configured SMTP From address
✅
Email is great for asynchronous workflows — send a task before bed, wake up to the completed result in your inbox.
Provider reference

Common IMAP and SMTP server settings:

Provider IMAP Host IMAP Port SMTP Host SMTP Port
Gmail imap.gmail.com 993 smtp.gmail.com 587
Outlook / 365 outlook.office365.com 993 smtp.office365.com 587
Yahoo Mail imap.mail.yahoo.com 993 smtp.mail.yahoo.com 587
Fastmail imap.fastmail.com 993 smtp.fastmail.com 587
ProtonMail Bridge 127.0.0.1 1143 127.0.0.1 1025
Custom / cPanel mail.yourdomain.com 993 mail.yourdomain.com 587

All connections use TLS. IMAP port 993 = implicit TLS. SMTP port 587 = STARTTLS. Port 465 = implicit TLS (also supported).
